# Quiz Generator System (C++ Console Application)

A menu-driven console-based Quiz Generator System developed in C++ as an academic Programming Fundamentals project.

The application allows users to attempt quizzes from multiple subjects at different difficulty levels with randomized questions, timed responses, grading, and permanent result storage.

---

# Project Overview

The system provides an interactive quiz platform that demonstrates practical implementation of core C++ programming concepts.

---

# Key Features

## Multi-Subject Quiz System

Supports:

- Programming Fundamentals
- Digital Logic and Design
- Mathematics

---

## Difficulty Levels

- Easy
- Medium
- Hard

---

## File-Based Question Management

Questions are stored externally in text files for easy updates.

---

## Randomized Questions

Questions are shuffled for every attempt.

Maximum:

**10 questions per quiz**

---

## Real-Time Evaluation System

Calculates:

- Correct answers
- Percentage
- Final Grade

Grades:

A+ to F

---

## Result Storage

Results are permanently saved in:

`results.txt`

Stored Information:

- Player Name
- Player ID
- Subject
- Difficulty
- Total Questions
- Attempted Questions
- Correct Answers
- Grade

---

## Input Validation

Validates:

- Player name
- Subject selection
- Difficulty selection
- Answer input

---

## Enhanced User Experience

Uses:

- Colored console output
- Sound feedback
- Timed question system
- Smooth transitions
